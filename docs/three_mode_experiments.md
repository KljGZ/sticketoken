# 三类 Sticky / Attractor 字符串的统一落地协议

## 1. 研究对象必须分开命名

本工程只把 `single_sticky` 称为原论文 Sticky Token 复现。另两类是本项目的扩展：

| 模式 | 搜索对象 | 几何目标 | 协议 |
|---|---|---|---|
| `single_sticky` | 同一 token 重复 8 次 | 最终相似度接近词元空间均值 `u` | 单边插入 |
| `multi_booster` | 长度 5 的多-token 串 | 低端提升、高端保持、非坍缩 | 单边插入 |
| `repulsive_attractor` | 长度 5 的多-token 串 | 共享触发后远离原句并形成紧致新簇 | 双边共享触发 |

`multi_booster` 不能被写成“论文发现的高 Sticky Token”；
`repulsive_attractor` 也不能被写成 AgentPoison 的完整复现。后者实现的是
self-repulsion 加 compactness，并用保守下界检查局部 uniqueness。

## 2. 共同实验控制

- 模型：`sentence-transformers/sentence-t5-base`，固定 revision
  `fc5d4628481afbbaaacd7af6bb07cf9d3865f781`。
- 最终表示全部 L2 归一化；搜索和验证均显式使用 FP32。
- 数据经长度过滤后，以 seed 42 在十个相似度秩分层中划分为
  search/validation/test = 20%/30%/50%。三者互斥且覆盖全部样本。
- 前缀、后缀、随机 token 边界三种插入同时进入搜索与认证。随机位置由
  SHA-256 和显式 seed 决定，不依赖 Python 进程 hash。
- search 只用于全词表筛选和离散优化；validation 用于候选选择；test 只做最终认证与图。
- 图中如果 30 次重复可能超过模型 256-token 上限，先按最大触发器长度固定截断原文，
  然后在所有横坐标复用同一原文。触发器本身不允许被截断，并记录截断率。

## 3. 模式一：论文一致的单-token 检测

合法 token 由 tokenizer 分析文件给出，模式一保留可达的特殊 token。词元平均相似度不构造
`M x M` 矩阵，而用归一化向量的精确恒等式：

```text
u = (||sum_i z_i||^2 - M) / (M(M-1))
```

累加和最终计算使用 FP64。搜索从 `r0 < u` 的 search 句对中分层抽 5 对，使用论文式
Sticky Score 排序全词表，取 Top 2%。验证和测试分别使用未参与搜索的低于均值句对；
Sentence-T5-base 的注册固定阈值为 `epsilon = 0.1106`。只有 validation 和 test 的
最大 `|r(t)-u|` 都不超过阈值，才标记 `certified=true`。

论文没有明确多句对下语义惩罚项的聚合方式。本实现显式采用“参考句向量与单-token
表示的平均余弦”，并记录被数值下界截断的非正分母数量。这是复现歧义，不伪装成原文唯一解释。

## 4. 模式二：多-token 单调增强串

低、高组阈值只由 search 分区的 30%/70% 分位数确定，再原样应用于 validation/test。
认证同时要求：

- 低组平均增益 `>= 0.03`；
- 低组中增益至少 `0.02` 的覆盖率 `>= 0.70`；
- 高组增益的 5% 分位数 `>= -0.02`；
- 全部观测中下降超过 `0.02` 的比例 `<= 0.05`；
- 插入后三种位置最坏动态范围保持率 `>= 0.70`；
- 与原始相似度的最坏 Spearman 相关 `>= 0.80`；
- 原始文本重新分词可实现率 `>= 0.95`；
- 沿五个 token 前缀逐步加入时，下降超过 `0.002` 的比例 `<= 0.10`。

所有约束通过前，可行候选永远排在不可行候选之前；不可行候选按归一化约束违反量排序，
不是用任意加权目标掩盖失败。全词表先做单-token 筛选，再用包含增益、保持和随机探索项的
256-token 池运行长度 5 的 CEM。代码还实现了查询式坐标 Beam 和遗传搜索，以便做算法消融。

## 5. 模式三：原句排斥的紧致吸引子串

同一候选串同时插入句对两侧。对每个插入位置，计算：

- 原句位移的 5% 分位数 `D_q05`；
- 插入后表示到公共均值的 95% 半径 `rho_q95`；
- 插入后表示的紧致损失 `1 - ||mean(z_triggered)||^2`；
- 插入后平均两两余弦；
- 低端提升和高端保持。

注册约束为 `D_q05 >= 0.35`、`rho_q95 <= 0.45`、高端 5% 增益
`>= -0.02`、低端平均增益 `>= 0.02`。另外要求：

```text
D_q05 - rho_q95 >= 0.02
```

它来自三角不等式，是公共中心远离已采样原句的保守下界。若该值为负，即使平均位移和平均
紧致性看似漂亮，也不能认证为新的局部唯一区域。该条件仍不等价于“远离整个良性流形”；
要主张全局 uniqueness，还需要良性聚类中心或流形覆盖实验。

模式三的 CEM 在搜索期间把排斥阈值从 0.05 连续提升到 0.35，但搜索档案在进入 validation
前会按最终完整约束重新排序，早期宽松阈值不能泄漏为最终可行性。

## 6. 结果解释边界

有限 test 集上的 `certified` 是注册分布上的经验认证，不是对所有自然语言的数学全称证明。
模式二对任意单位球查询严格不下降在几何上不可能；这里验证的是有限、各向异性的自然文本分布。
模式三适合“查询和键都共享触发器”的吸引子研究。若真实 RAG 中只有恶意文档带串，还必须另外
优化查询覆盖或 Top-k 排名，不能从紧致性和原句排斥直接推导检索劫持成功。
